# 🏭 Idle Factory - Jogo Clicker Idle

Um jogo idle clicker divertido e viciante onde você clica para ganhar dinheiro e compra upgrades para automatizar sua produção!

## 🎮 Como Jogar

### Objetivo
Ganhe o máximo de dinheiro possível clicando no botão e comprando upgrades para automatizar sua produção.

### Mecânicas Básicas
- **Clique no botão** para ganhar dinheiro
- **Compre upgrades** na loja para aumentar sua produção
- **Desbloqueie achievements** para ganhar bônus
- **Salve seu progresso** automaticamente ou manualmente

### Tipos de Upgrades

#### 🖱️ Upgrades de Clique
- **Melhor Mouse**: Aumenta o valor por clique
- **Clique Duplo**: Dobra o valor por clique
- **Clique Dourado**: Triplica o valor por clique

#### ⚡ Upgrades Passivos
- **Auto Clicker**: Gera dinheiro automaticamente por segundo
- **Mega Clicker**: Gera mais dinheiro por segundo
- **Fábrica**: Gera muito dinheiro por segundo
- **Império**: Gera dinheiro em massa por segundo
- **Universo**: Gera dinheiro astronômico por segundo

### 🏆 Achievements
Complete objetivos para desbloquear achievements e ganhar bônus:
- Primeiro clique
- Cem cliques
- Mil cliques
- Primeira compra
- Rico ($1000)
- Milionário ($1M)
- Renda passiva
- Magnata

### 💾 Sistema de Salvamento
- O jogo salva automaticamente a cada 30 segundos
- Você pode salvar manualmente clicando no botão "Salvar Jogo"
- Seu progresso é mantido mesmo fechando o navegador

### 🔄 Resetar Jogo
Se quiser começar do zero, clique no botão "Resetar" no rodapé.

## 🚀 Como Executar

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Comece clicando no botão grande
3. Compre upgrades quando tiver dinheiro suficiente
4. Divirta-se!

## 🎨 Características

- **Interface moderna** com gradientes e animações
- **Design responsivo** que funciona em desktop e mobile
- **Animações suaves** e efeitos visuais
- **Sistema de notificações** para achievements
- **Formatação inteligente** de números (K, M, B, T)

- HTML5

## 🎯 Dicas de Jogo

1. **Comece clicando** para acumular dinheiro inicial
2. **Compre upgrades de clique** primeiro para aumentar sua produção manual
3. **Invista em upgrades passivos** para automatizar sua renda
4. **Complete achievements** para ganhar bônus extras
5. **Seja paciente** - os upgrades mais poderosos custam muito!
